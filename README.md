 🌦️ WEATHER APPLICATION

A simple and elegant Weather Application built with HTML, CSS, JavaScript, and Python, which allows users to check real-time weather information of any city using an external weather API.  

✨ Features
- 🔍 Search weather by city name  
- 🌡️ Shows temperature, humidity, and condition  
- 📱 Responsive and clean UI design  
- ⚡ Fetches live data from API
  
🛠️ Tech Stack
- 🎨 Frontend: HTML, CSS, JavaScript  
- 🐍 Backend: Python    
- ☁️ API: OpenWeatherMap
